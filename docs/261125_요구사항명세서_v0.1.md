### 2.8 부가 기능 (요건 외, ID 없음)

「소프트웨어 요건」 목록에는 없지만, 기존 `smart-voca` 에 있던 기능이므로 v0.1 에 포함한다. 가산점 대상이 아니다. 데이터 설계서 §6.1 의 규칙을 따른다.

| 명세 | 확인 | 상태 | 결정 |
|---|---|---|---|
| 단어장 전체 초기화: 단어, 배정, 암기 기록, 시험 회차와 문항을 모두 지운다. "전체삭제" 를 직접 입력해야 실행되고, 한 트랜잭션으로 처리한다. 실행 후 되돌릴 수 없음을 화면에 명시한다 | 시연·DB | 구현 완료 (단위 테스트, 로컬 실행 확인) | 데이터 설계서 §6.1 |
