## 3. 통합(E2E) 테스트 시나리오

| 시나리오 | 검증 경로 | 통과 기준 |
|---|---|---|
| 기본 전체 흐름 | `/` → `/words` → `/study` → `/study/next` → `/exam` → `/exam/<id>/submit` → `/stats` → `/words/reset` | 전 경로 `200`/`302`, 데이터 집계 일치, 오입력 초기화 차단 후 `"전체삭제"` 정상 초기화 |
| 설정 반영 흐름 | `/settings` 저장 → `/exam/new`, `/study` 확인 → `/settings/reset` | 시험 기본 문제 수·방향·형식 및 오늘 암기 카드 수 즉시 반영 |
| 계정 격리 흐름 | `alice` 가입·학습·시험 → 로그아웃 → `bob` 가입 → `/stats`, `alice`의 `/exam/<id>/result` 접근 | `bob` 통계 `0`, 타인 시험 `404`, `alice` 재로그인 시 기존 이력 복원 |
| 공개/읽기 전용 흐름 | 공개 계정·비공개 계정 생성 → `/ranking`, `/ranking/<id>`, `POST /ranking/<id>`, `/settings/privacy` | 공개 계정 `200`, 비공개 `404`, `POST` 수정 시도 `405`, 공개 토글 후 `200` |
